拾流 · 网页影音下载器  1.2.0

安装到 Chrome 和 Edge

1. 把 ZIP 解压到准备长期保留的文件夹。如果已经有包含 manifest.json 的 extension 文件夹，可以直接用它。
2. 在 Chrome 地址栏输入 chrome://extensions/。在 Edge 地址栏输入 edge://extensions/。
3. 在各自的扩展管理页开启“开发者模式”，点击“加载已解压的扩展程序”或“加载解压缩的扩展”，选择直接包含 manifest.json 的文件夹。
4. 两个浏览器可以选同一文件夹。安装后保留该文件夹。可以从浏览器的扩展菜单把拾流固定在工具栏。

如果已安装旧版，把新版文件解压到原扩展文件夹并覆盖旧文件，再分别到两个浏览器的扩展管理页点击拾流卡片上的“重新加载”。确认卡片显示 1.2.0，然后刷新播放器网页并重新播放几秒，以便拾流记录新的媒体请求。

下载网页中的媒体

打开目标网页并播放几秒，再点击拾流图标。工具栏上的数字表示当前标签页已发现的资源数量。刚安装时，若网页已打开且列表为空，先刷新网页，再播放一次并点击“重新扫描”。

• 对于 MP4、WebM、MP3、M4A 等文件，点击“下载”。如果打开拾流的文件下载页，点击“选择位置并下载”并保持此页打开。在浏览器直接接管下载时，按 Ctrl+J 可查看保存位置和下载状态。
• 对于 HLS（M3U8）点播，点击“打开”，在新页中选择画质或音轨。如果画面和声音在同一轨道，两者会一起保存。独立音轨可以另选一次，另存为音频文件。
• 对于 DASH（MPD），本版提供“保存清单”，可得到描述轨道和分片地址的 .mpd 文件。

保存 HLS 文件

1. 等待拾流检查播放列表和媒体格式，然后点击“选择位置并下载”。在浏览器的保存对话框中选择文件夹、确认文件名并保存。
2. 拾流逐个读取分片并写入文件。请保持 HLS 下载页打开，在该页查看进度或点击“取消”。看到保存完成提示后，到刚才选择的文件夹中打开文件。
3. 中途取消或写入失败时，拾流会放弃本次写入。如果选择了新文件名，目标文件夹里可能留下空文件。重新开始时会从头下载。

HLS 下载需要浏览器允许此扩展打开文件保存对话框。若对话框不可用，请确认已使用支持此功能的 Chrome 或 Edge，并允许向所选位置写入文件。

支持范围

HLS 导出支持未加密、已经结束的点播列表，包括常见的 MPEG-TS 和带初始化片段的 fMP4。TS 源保存为 .ts，fMP4 视频源保存为 .mp4，独立音频依封装保存。每个 HLS 输出文件上限为 4 GiB（4,096 MiB），最多 50,000 个媒体分片。单个媒体分片或初始化片段的上限为 512 MiB。

直播、DRM、加密的 HLS、需要转码或重新封装的复杂分段内容超出本版范围。若页面使用 blob: 临时播放地址，拾流会寻找对应的网络资源。若下载显示 HTTP 401、403 或 412，请确认原网页仍能播放，刷新后播放几秒，再打开拾流重新扫描。

网站访问权限

为识别没有文件后缀的媒体以及来自其他域名的播放器和 CDN，拾流会在浏览器内检查 HTTP / HTTPS 请求的响应类型、文件名和长度。打开面板或点击“重新扫描”时，还会检查当前网页和可访问的内嵌播放器。资源清单暂存在浏览器会话中，关闭标签页后清理。媒体识别和分片合并在本机完成，下载直接访问媒体源站。

部分媒体源会验证请求的来源站点。拾流在下载页重用成功播放时观察到的 Origin、Referer，并把临时规则限制在该下载标签页和同一媒体源。原请求携带 Cookie 时，浏览器可为同一媒体源沿用现有会话。拾流只记录是否携带 Cookie，不保存其值。
